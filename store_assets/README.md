# Play Store Assets

Place production listing assets here before submitting to Google Play Console.

## Required assets

| Asset | Size | Path |
|-------|------|------|
| App icon | 512×512 PNG | `icon/play_store_icon.png` |
| Feature graphic | 1024×500 PNG | `feature_graphic/feature.png` |
| Phone screenshots | Min 2, 16:9 or 9:16 | `screenshots/phone/` |
| Tablet screenshots | Optional | `screenshots/tablet/` |

## Short description (80 chars max)

AI travel planner — trips, packing, budget, journal, and maps. Free with ads.

## Full description

Use feature highlights from the app: AI itinerary, offline-first sync, expense tracking, document vault, weather, currency converter, and journal.

## Content rating

Complete the IARC questionnaire in Play Console. Declare ads (AdMob) and user-generated content (journal).
